# Standalone report contract

- Store generated analysis reports in this repository-root `reports/` directory. Do not place them in `paper/reports/` or reference them from manuscript `.tex` files.
- Use descriptive lowercase snake-case filenames with a `.md` extension unless a task prompt specifies an exact name.
- Write GitHub-flavored Markdown with `#`/`##` headings, lists, tables, links, and fenced code blocks as appropriate.
- Delimit inline mathematics with `$...$` and display mathematics with `$$...$$` on separate lines. Keep LaTeX mathematics inside those delimiters; do not use document-level LaTeX commands such as `\section`, `\input`, or `\clearpage`.
- Cite repository evidence with repository-relative paths plus labels, sections, or line anchors. Format web sources as Markdown links and paths, commands, labels, and citation keys as inline code.
- A report artifact alone never authorizes manuscript edits or a LaTeX build. Follow the task prompt for any separate manuscript edits and their verification.
